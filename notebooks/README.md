# Notebooks

This directory contains exploratory notebooks for analysis, derivation, visualization, and early-stage prototyping.

## Purpose

Notebooks should support flexible scientific exploration while keeping provisional work separate from polished simulations and manuscripts.

## Suggested Contents

- Concept sketches and mathematical derivations.
- Exploratory data analysis.
- Figure prototypes.
- Simulation experiments before they are promoted to `simulations/`.
- Notes on open questions and possible paper sections.

# Simulations

This directory contains computational experiments for the Induced Dependence scientific program.

## Purpose

Simulations should provide concrete examples, stress tests, and visual evidence for claims made in the master paper and derived papers.

## Suggested Contents

- Minimal toy models of induced dependence.
- Domain-specific simulations for Bell systems, ecology, and AI observability.
- Reproducible scripts with clear parameters.
- Generated figures or data outputs, when appropriate.
- Notes connecting each simulation to a manuscript claim.

## Current Simulations

- `minimal_induced_dependence.py` - Demonstrates two independent binary variables becoming dependent under a shared constraint.
- `observational_deformation_kl.py` - Estimates KL-based observational deformation induced by a rigid truncation filter.

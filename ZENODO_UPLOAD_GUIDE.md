# Zenodo Upload Guide

Use this guide to publish the initial archived version of the Induced Dependence Scientific Program on Zenodo.

## Recommended Upload Type

Publication type:

```text
Working paper
```

Alternative if Zenodo asks for a broader category:

```text
Other
```

```text

```

## Description

```text
Initial research package for the Induced Dependence scientific program. The repository includes a master paper draft, formal definitions, mathematical foundations materials, a minimal simulation, conceptual figures, bibliography, licensing, and manuscript outputs.
```


## After Publication

Zenodo will generate a DOI. After the DOI exists, update:

```text
CITATION.cff
```

Replace:

```text
https://doi.org/10.5281/zenodo.TBD
```

with the real Zenodo DOI URL.

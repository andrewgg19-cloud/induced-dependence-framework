# Manuscript Outputs

This directory is reserved for consolidated, exportable manuscript versions.

## Purpose

The working source files in `master_paper/` are written in Markdown because they are easy to edit, compare, version, and reorganize.

This directory should contain more polished manuscript outputs, such as:

- Word documents (`.docx`)
- PDFs (`.pdf`)
- LaTeX files (`.tex`)
- submission-ready manuscript versions

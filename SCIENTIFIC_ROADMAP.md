# Scientific Roadmap

This document tracks the development path for the Induced Dependence scientific program.

## Program Goal

Develop induced dependence as a general scientific framework for understanding dependencies that are not merely intrinsic to isolated components, but are produced, amplified, revealed, or transformed by context, observation, intervention, or shared constraints.

## Core Research Questions

- What is induced dependence, and how does it differ from ordinary dependence, correlation, causation, coupling, or contextuality?
- Under what conditions does induced dependence appear?
- Can induced dependence be formally detected, measured, or simulated?
- How does the same framework operate across physical, ecological, computational, and mathematical domains?
- What explanatory advantages does the framework provide over existing language?

## Manuscript Sequence

1. Master paper: define the framework, establish the vocabulary, and present the general theory.
2. Mathematical foundations paper: formalize definitions, assumptions, propositions, and minimal models.
3. Bell systems paper: test the framework against nonclassical correlation structures.
4. Ecology paper: apply the framework to interdependent adaptive systems.
5. AI observability paper: apply the framework to monitoring, latent structure, and intervention in AI systems.

## Simulation Priorities

- Minimal abstract model showing induced dependence under a shared constraint.
- Network model where dependence appears after an environmental or observational intervention.
- Bell-style correlation simulation or conceptual model.
- Ecological perturbation model with cascading induced coupling.
- AI observability model where monitoring changes apparent dependency structure.

## Near-Term Milestones

- Draft full outlines for each manuscript.
- Define a compact glossary of core terms.
- Identify candidate mathematical formalisms.
- Create minimal simulations connected to specific claims.
- Build an initial bibliography for each paper.

## Open Questions

- Is induced dependence best framed probabilistically, causally, informationally, dynamically, or categorically?
- Should the master paper remain broad and conceptual, or include a formal core theorem?
- Which domain provides the strongest motivating example?
- What would count as empirical evidence for induced dependence rather than ordinary correlation?
